# SteamDrop — Random Steam Game Roulette Wheel

An ultra-responsive, CS:GO-inspired mechanical roulette wheel designed for content creators, streamers, and gamers. Spin across 180,000+ Steam games with rich trailer previews, direct Steam client deep links, streamer mode for OBS, and authentic English & Arabic localization.

---

## 🎮 Key Features

- **CS:GO-Style Roulette Animation**: Smooth cubic-bezier deceleration physics with dynamic tick audio synthesis (zero external audio files needed via Web Audio API).
- **180,000+ Steam Games Catalog**: Syncs directly with complete Steam catalog datasets with multi-tier CDN cover-art failover.
- **Content Creator & Streamer Mode**:
  - One-click OBS Clean Mode (`[S]` or checkbox) to hide headers, disclaimers, and control clutter.
  - Floating `[Esc]` exit button and toast notification.
- **Creator Hotkeys Engine**:
  - `Spacebar` / `Enter`: Spin wheel, skip animation mid-spin, or trigger "Spin Again".
  - `Esc`: Close modals or exit Streamer Mode.
  - `M`: Toggle Sound (ON / Muted).
  - `S` / `O`: Toggle Streamer Mode.
  - `F`: Toggle Fast Spin (3-second mode).
- **Instant Full Inspection Modal ("Rolled Games")**:
  - Search and inspect all games rolled during any spin.
  - One-click copy game title button.
  - Direct Steam store links & Steam Desktop Client protocol links (`steam://store/<appid>`).
- **Trailer & Screenshot Media Showcase**: In-modal trailer playback and full resolution hero banners for winning drops.
- **Full Arabic & English Localization**: Real-time language switcher with authentic Saudi/Gulf gaming slang and automatic directional flip (RTL/LTR).
